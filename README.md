# Sal Torre

Sal Torre's workspace in the StackPack community.

Everything here is made for Sal Torre. Prompts, scripts, small tools, notes worth keeping.

## How it works

There is nothing to install and nothing to push. The community keeps this repo, and
the assistant does the writing. Ask in the Discord and it lands here, checked for keys
and anything risky before it is saved.

## What is kept out

- No passwords, keys or personal details.
- No client's or employer's private work.
- Nothing dangerous, and nothing that arrives without a scan.
